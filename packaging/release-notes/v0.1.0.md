# FLXXX3 v0.1.0 – Standalone DJ App for Android and the DDJ-FLX4

First public release. A touch-first DJ app for Android tablets and phones, built on [Mixxx](https://github.com/mixxxdj/mixxx), made for the Pioneer DDJ-FLX4.

## What it does
- Plug in the DDJ-FLX4 via USB: 4-channel audio straight to the controller (own low-latency USB driver) and full MIDI mapping, no PC needed
- Reads Rekordbox-exported USB sticks (tracks, playlists, hotcues, memory cues, beat grids, waveforms); choose the stick or the device's own music folders on the SOURCE screen
- Two screen layouts: XDJ (stacked waveforms) and CDJ (one panel per deck with BEAT LOOP, KEY SHIFT, BEAT JUMP and a beat-match aid showing the bars to the next cue)
- Library with BROWSE, TAG LIST, PLAYLIST, SEARCH and a track filter (BPM, key, rating, colour)
- Beat FX (delay, echo, ping pong, reverb, flanger, phaser, filter) and Color FX
- Sync, quantize, loops, hotcues, tempo ranges, master tempo

## Good to know
- Early release. Tested on a Galaxy Tab A11 (SM-X130) and a Galaxy S25, with the DDJ-FLX4 only
- Needs Android 10 or newer (64-bit ARM) and a USB host port; plug in the DDJ-FLX4 before starting the app
- The APK is debug-signed: allow "install unknown apps" and sideload it
- No sampler, crates, auto-DJ or streaming; no other controllers yet
- If the Rekordbox Android app is installed, disable it while using FLXXX3 (it grabs the controller when it is plugged in)

## Install
1. Download `FLXXX3-v0.1.0.apk` and open it on the device (or `adb install -r --no-incremental FLXXX3-v0.1.0.apk`)
2. Connect the DDJ-FLX4 and a Rekordbox-exported USB stick (a powered hub is recommended), then start FLXXX3
3. Choose the stick on the SOURCE screen and press OPEN
