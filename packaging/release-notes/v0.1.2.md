# FLXXX3 v0.1.2 – Standalone DJ App for Android, Windows and the DDJ-FLX4

Feature update: a Windows installer, memory cues, instant doubles, auto gain, a reworked deck display and a much smaller Android download.

## Important (Android): uninstall v0.1.1 first
From this version on FLXXX3 is signed with its own release key (v0.1.0 and v0.1.1 were debug-signed). Android does not install it over an older version: **uninstall FLXXX3 once, then install v0.1.2**. Your settings are lost this one time; later updates install over v0.1.2 and keep them.

## New
- **Windows installer**: `FLXXX3-v0.1.2-windows-setup.exe` installs FLXXX3 for your user (no administrator rights needed), with a start menu entry and an optional desktop icon
- **CUE/LOOP CALL** (FLX4): without a loop the buttons jump to the previous / next Rekordbox memory cue (a memory loop starts its loop); the called point becomes the CUE. During a loop they still halve / double it, like before
- **INSTANT DOUBLES**: press LOAD twice quickly to load the track of the other deck at the same position (playing if it plays)
- **AUTO GAIN** (UTILITY, on by default): every track is measured once (loudness, EBU R128) and played at about the same loudness, never louder than its peak allows. With AUTO GAIN off the level is the same as in v0.1.1
- **KEY SHIFT in the XDJ view**: arrow below the deck number
- **ABOUT** (UTILITY > ADVANCED SETTINGS): version, source code link and all licenses

## Changed
- **XDJ view**: larger time and tempo (like the CDJ view), key in white without a frame
- **CDJ view**: larger key without the "KEY" label; BEAT JUMP shows the direction arrows again (inner side of each pair), the page switch stands apart
- **Android download 62 MB instead of 259 MB**: unused parts of Mixxx and Qt are left out (translations, other controllers, legacy skins, streaming, vinyl control, stems and others) and the libraries are compressed
- **Windows**: FLXXX3 has its own icon and keeps its settings in `%LOCALAPPDATA%\FLXXX3` (separate from an installed Mixxx)

## Good to know
- Tested on a Galaxy Tab A11 (SM-X130, Android 16) and on Windows 11, both with the DDJ-FLX4; still not tested on Android 10–13 devices – feedback welcome
- **Android**: needs Android 10 or newer (64-bit ARM) and a USB host port; plug in the DDJ-FLX4 before starting the app. If the Rekordbox Android app is installed, disable it while using FLXXX3 (it grabs the controller when it is plugged in)
- **Windows**: needs Windows 10 or 11 (64-bit). Connect the DDJ-FLX4 directly (not through a USB hub) – through a hub it did not send MIDI on the test computer. The installer is not code-signed: Windows SmartScreen shows "Windows protected your PC" – click "More info" and "Run anyway"
- The first measurement of a track (AUTO GAIN) runs in the background after loading; the gain is applied when the deck is stopped, never while it plays
- No sampler, crates, auto-DJ or streaming; no other controllers yet

## Install
**Android**
1. Uninstall an older FLXXX3 (see above)
2. Download `FLXXX3-v0.1.2.apk` and open it on the device (or `adb install --no-incremental FLXXX3-v0.1.2.apk`); allow "install unknown apps"
3. Connect the DDJ-FLX4 and a Rekordbox-exported USB stick (a powered hub is recommended), then start FLXXX3
4. Choose the stick on the SOURCE screen and press OPEN

**Windows**
1. Download `FLXXX3-v0.1.2-windows-setup.exe` and run it (see the SmartScreen note above)
2. Connect the DDJ-FLX4 and a Rekordbox-exported USB stick, then start FLXXX3 from the start menu
3. Choose the stick on the SOURCE screen and press OPEN
